# Presentación — arquitectura e-commerce

Deck autodidáctico para la sustentación. Un solo archivo HTML, sin `npm`.

## Abrir

1. Abre `arquitectura-ecommerce.html` en Chrome (o la copia en Descargas: `sdd-presentacion-arquitectura-ecommerce.html`).
2. Pantalla completa: **F** (o `F11`).
3. Avanzar: **→** **↓** **Espacio** **PageDown**. Retroceder: **←** **↑** **Backspace**.
4. Inicio / fin: **Home** / **End**.
5. Salir de pantalla completa: **Esc**.

Click en el tercio derecho avanza; en el izquierdo retrocede.

## Contenido

Fuente de verdad: `../sdd-core-ecommerce.html`. Diagramas SVG van **dentro** de las diapositivas; no hace falta abrir `.drawio` durante la charla.
